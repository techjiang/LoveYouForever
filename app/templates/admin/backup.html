自动备份怎么做？

配合系统 crontab 使用，比如每天凌晨 3 点备份一次： 

0 3 * * * cd /path/to/loveyouforever && .venv/bin/flask backup --note "每日自动备份"

也可以用命令行：flask backup、flask backup-list、flask restore 文件名。
